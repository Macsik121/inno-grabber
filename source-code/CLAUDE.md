# InnoGrabber - Innovation Campus Materials Downloader

## Описание проекта

Автоматизированный скрипт для скачивания учебных материалов с платформы `innovationcampus.ru` (на базе LMS Moodle) для локального офлайн-изучения.

## Архитектура

**Технологический стек:**
- Python 3.10+
- Playwright (браузерная автоматизация, генерация PDF из страниц)
- BeautifulSoup4 / markdownify (конвертация HTML в Markdown)
- yt-dlp (скачивание потокового видео)

**Принцип разделения:**
Код разделен на **Универсальное Ядро** (логика папок, скачивание, сохранение файлов) и **Профиль Курса** (конфигурация HTML-селекторов). Если появится новый курс с другой версткой, достаточно добавить его селекторы в настройки, не переписывая ядро.

## Алгоритм работы

### Этап 1: Авторизация и запуск

1. Скрипт запускает браузер Chrome/Chromium в видимом режиме с сохранением сессии (пользовательский профиль)
2. Пользователь вручную логинится, открывает главную страницу нужного курса и нажимает `Enter` в консоли
3. Скрипт перехватывает управление и начинает сбор материалов

**Auto-waiting:** Playwright автоматически дожидается прогрузки элементов перед взаимодействием (не нужны "слепые" клики)

**Rate Limiting:** Паузы 1.5-3 секунды между переходами по материалам для имитации поведения человека и защиты от бана

### Этап 2: Сбор карты курса

Скрипт парсит главную страницу курса:
- Извлекает название курса
- Находит все Разделы (главы/модули)
- Внутри каждого раздела собирает список ссылок на Материалы (название + URL)
- Создает корневую папку курса и нумерованные подпапки разделов

### Этап 3: Обработка материалов

Скрипт автоматически определяет тип материала по содержимому страницы:

#### Тип 1: Прямой файл (Презентация PDF или архив ZIP)

**Признак:** Ссылка ведет напрямую на скачивание файла или страница-обертка с единственным файлом

**Действие:** Файл скачивается напрямую в папку материала. Подпапки не создаются

#### Тип 2: Модуль "Книга" (Многостраничная теория/лабораторная)

**Признак:** На странице есть меню `Дополнительно -> Печатать книгу`

**Действие:**
1. Скрипт переходит на страницу "Печатать книгу" (все главы уже склеены в один документ)
2. Использует `page.pdf()` для прямого сохранения в `[Название_материала].pdf` (без системного диалога печати!)
3. Дополнительно сканирует страницу на наличие видео/архивов и докачивает их в `videos/` и `others/`

#### Тип 3: Обычная HTML-страница (Теория без печати, Задание, Тест)

**Признак:** Нет кнопки "Печатать книгу", но есть текстовый/медиа контент

**Оглавление:**
- Если есть оглавление/навигация — скрипт собирает ссылки на все подстраницы
- Если нет — работает с текущей страницей

**Обход подстраниц:**
- Формируется единый файл `[Название_материала].md` (склейка по оглавлению)
- **Текст, код, таблицы, вопросы тестов** → конвертируются в Markdown
- **Картинки (`<img>`)** → скачиваются в `images/`, в текст вставляется `![alt](images/img_01.png)`
- **Видео (`<video>`, `<iframe>`)** → скачиваются через yt-dlp в `videos/`, в текст вставляется ссылка на файл + оригинальный URL
- **Вложенные файлы (`.zip`, `.docx`, `.py`)** → скачиваются в `others/`, в текст вставляется ссылка

#### Тип 4: Необычная страница (Fallback)

**Признак:** Страница не подходит под типы выше

**Действие:**
1. Создается `[Название_материала].md` с пометкой `ВНИМАНИЕ: Нестандартная страница` и ссылкой
2. Сохраняется полный скриншот (`full_page_screenshot.png`) и сырой HTML (`others/raw_page.html`)
3. Материал заносится в список "Необычных" в главном отчете

## Ключевые решения из проектирования

### Навигация по курсу

Не имитировать клики пользователя (открыл-закрыл-вернулся). Вместо этого:
1. Собрать все ссылки на материалы в единый список за один проход
2. Переходить по URL напрямую без навигации по меню

### Формат сохранения

Использовать `.md` (Markdown) вместо `.txt`:
- При открытии в просмотрщике (Obsidian, VS Code, Notion, GitHub) получается полноценная статья с встроенными картинками
- Технически это простой текстовый файл

### Экспорт в PDF

Функция "Печатать книгу" в Moodle уже склеивает все главы оглавления в один документ. Playwright может сохранить эту страницу напрямую в PDF через `page.pdf()` без системного диалога печати.

### Обработка видео

Видео редко лежит прямым `.mp4` файлом. Обычно это встроенный плеер (YouTube, Rutube, VK Video, Kinescope или HLS/m3u8). Playwright находит ссылку на плеер и передает её в `yt-dlp`.

## Идея: JavaScript + Python подход (требует проработки)

**Суть подхода:**
1. Сохранить HTML-код ключевых страниц курса:
   - `some-course-nav-links.html` — навигация по курсу (список разделов и материалов)
   - `some-course-main-page.html` — главная страница курса

2. Запустить JavaScript-код для извлечения `textContent` из HTML-элементов:
   - Каждый тип материала (презентация, теория, задание, тест) имеет свой CSS-класс
   - JavaScript собирает точные текстовые метки материалов

3. Python Playwright использует эти текстовые метки для поиска элементов на странице:
   - Вместо хрупких CSS-селекторов — поиск по точному тексту элементов
   - Playwright может находить элементы по `text_content` или `get_by_text()`

**Преимущества:**
- Более устойчиво к изменениям верстки (текст элементов меняется реже, чем CSS-классы)
- Можно заранее проанализировать HTML и подготовить список материалов
- Упрощается адаптация под разные курсы — достаточно собрать текстовые метки

**Статус:** Идея не реализована, требует проработки архитектуры

**Пример из `courses-html/mobile-dev/`:**
- `mobile-course-nav-links.html` — содержит структуру навигации с классами `courseindex-section`, `courseindex-link`
- `mobile-course-main-page.html` — главная страница с заголовком курса и модулями
